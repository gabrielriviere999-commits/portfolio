INSTALLATION DE STEAM SUR MX LINUX

1) Activer l'architecture 32 bits
sudo dpkg --add-architecture i386
sudo apt update

2) Installer les bibliothèques graphiques 32 bits
sudo apt install libgl1-mesa-dri:i386 libgl1-mesa-glx:i386

3) Méthode A (recommandée) : Installer Steam depuis les dépôts MX/Debian
sudo apt update
sudo apt install steam

→ Lancer Steam depuis le menu.
→ Steam téléchargera automatiquement la version complète.

4) Méthode B (alternative) : Installer le .deb officiel de Valve
Télécharger le fichier :
https://repo.steampowered.com/steam/archive/stable/steam-launcher_latest-stable_all.deb

Installer le fichier téléchargé :
sudo apt install ./steam-launcher_latest-stable_all.deb

→ Lancer Steam depuis le menu.
→ Steam téléchargera automatiquement la version complète.

5) Activer Proton si pas activé (pour les jeux Windows)
Dans Steam :
  - Ouvrir Paramètres
  - Aller dans "Compatibilité"
  - Cocher "Activer Steam Play pour tous les titres"
  - Choisir "Proton Experimental" ou "Proton 8"

6) (Optionnel) Installer GameMode pour de meilleures performances
sudo apt install gamemode

7) Modifier les options de montage dans gnome-disk-utility
Pour que l'utilisation de disque NTFS/exFAT externe fonctionne
Remplacer nosuid,nodev,nofail,noauto,x-gvfs-show par nosuid,nodev,nofail,x-gvfs-show,uid=1000,gid=1000,umask=000

Scripts tableau clipboard ascii et changeurs de casse.
Ces scripts ont été testés sur Linux, Windows, Android, macOS.
Seul sur Windows, les caractères tels que des accents et ç sont cassés.
Les scripts sont en dessous du texte Télécharger

Vous devez utiliser une police régulière dans l'application concernée comme monospace ou mono...
ou regular... pour que le tableau soit affiché sans décalages lors de la lecture.
Vous pouvez modifier le séparateur ; et la largeur maximale du tableau en modifiant le script.
Quand le tableau atteint la largeur maximale, le texte passe à la ligne :
aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa;bbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbb
c;d;e;f
+-------------------------------------------------------+------------------------------------------------------+---+---+
| aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa | bbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbb |   |   |
| aaaaaaaaaaaaa                                         | bbbbbbbbbbbbb                                        |   |   |
+-------------------------------------------------------+------------------------------------------------------+---+---+
| c                                                     | d                                                    | e | f |
+-------------------------------------------------------+------------------------------------------------------+---+---+

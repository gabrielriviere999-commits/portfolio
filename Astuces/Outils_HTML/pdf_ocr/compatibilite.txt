=== Compatibilité minimale OS pour pdf_ocr ===

Windows :
- Windows XP ............. X Pas de WebAssembly utilisable (Chrome 49 / Firefox ESR bridé)
- Windows Vista .......... X Trop ancien, navigateurs bloqués
- Windows 7 .............. V️ Minimum recommandé (Chrome 57+ / Firefox 52+)
- Windows 8 / 8.1 ........ V️
- Windows 10 / 11 ........ V️

Android :
- Android 4.x (WebView) .. X Pas de WebAssembly
- Android 4.4 + Firefox .. ⚠️ Fonctionne parfois (ex : Firefox 68), mais NON garanti
- Android 5.0 ............ V️ Minimum officiellement supporté
- Android 6+ ............. V️

iOS :
- iOS 9 / 10 ............. X Pas de WebAssembly utilisable
- iOS 11 ................. V️ Minimum supporté
- iOS 12+ ................ V️

macOS :
- macOS 10.10 / 10.11 .... X Safari trop ancien (pas de WASM correct)
- macOS 10.12 Sierra ..... V️ Minimum supporté
- macOS 10.13+ ........... V️

Linux :
- Dépend du navigateur ... V️ Chrome 57+ / Firefox 52+


=== Compatibilité minimale navigateurs ===

Chrome .......... 57+ (WebAssembly OK)
Firefox ......... 52+ (WebAssembly OK)
Edge (Chromium) . 79+ (WebAssembly OK)
Safari .......... 11+ (WebAssembly OK)
Opera ........... 44+ (WebAssembly OK)

Navigateurs non supportés / très limités :
- Chrome 49 (Windows XP)
- Firefox 52 ESR sur XP (WASM désactivé / bridé)
- WebView Android 4.x
- Safari < 11
- Internet Explorer / Edge Legacy

Notes :
- Des appareils plus anciens (ex : Android 4.4 + Firefox 68) peuvent parfois fonctionner,
  mais ce n’est PAS garanti et ce n’est pas une cible officielle.
- Windows XP est considéré comme non supporté, même si certains navigateurs tiers
  peuvent charger partiellement la page.

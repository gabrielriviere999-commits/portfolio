Pour changer la rotation d'écran tout en gardant les bonnes positions pour l'écran tactile sur XFCE :
(GNOME ou KDE n'ont pas besoin de ces scripts, aller dans les paramètres suffit.)
Vous pouvez exécuter un des scripts rotate_X.sh
https://gabrielriviere999-commits.github.io/portfolio/Astuces/change_rotation/change_rotation.zip

Avant de l'éxécuter, il faut trouver le nom du SCREEN et TOUCH.
Trouver le nom de l’écran (SCREEN) :
xrandr --query
Vous verrez une ligne comme eDP-1 connected ...
Quelques exemples : eDP-1, eDP-0, eDP, LVDS-1, LVDS

Trouver le nom du/des périphérique(s) tactile(s) (TOUCH) :
xinput list
Vous devez repérer votre écran tactile, parfois dans Virtual core pointer
Exemple : ELAN9009:00 04F3:2EC1

Pour exécuter les scripts :
Ouvrir le terminal dans le dossier contenant les scripts
chmod +x rotate_*.sh
Vous pouvez ajouter les fichiers à votre barre d'outils.
Lors de la déconnexion/extinction/redémarrage, tout redevient à la normale.

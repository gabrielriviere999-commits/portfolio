🌐 Français
TABLEAU ASCII
-------------
Une application qui permet de faire des tableaux comme ceux générés par MySQL
par exemple.
- écrivez votre texte séparé par des ; dans le champ tout en haut.
- Puis appuyez sur "Convertir" pour générer le tableau, il apparait dans le champ
tout en bas.
- Cliquez sur "Copier" pour copier le texte dans votre presse papiers.
- Le bouton "Effacer" efface ce que vous avez tappé dans le premier champ + le
tableau généré.
Vous pouvez changer le séparateur de données ainsi que la largeur maximale du
tableau généré, lorsque le tableau atteint la largeur maximale, le texte passe
à la ligne dans les cellules.
Le bouton "Valeurs par défaut" permet de rétablir le séparateur et la largeur
par défaut.
Vous pouvez la lancer par la quick tile ou l'écran d'accueil.


ÉDITEUR DE TEXTE
----------------
Un éditeur de texte simple, léger et compatible avec les appareils anciens.
Conçu pour être rapide, minimaliste et fiable, sans dépendances lourdes ni
fonctionnalités superflues.

Fonctionnalités principales :
- Multi-onglets
- Ouverture et sauvegarde via le sélecteur de fichiers Android
- Recherche avec surlignage et navigation
- Remplacement de texte
- Dupliquer la ligne courante
- Supprimer la ligne courante
- Coller à la position exacte du curseur
- Bouton pour aller directement en bas du fichier
- Interface transparente
- Compatibilité Android 4.1+

Raccourcis clavier (clavier physique ou Unexpected Keyboard) :
- Ctrl + Z : Annuler
- Ctrl + Y : Rétablir
- Ctrl + A : Tout sélectionner
- Ctrl + C : Copier
- Ctrl + V : Coller
- Ctrl + X : Couper
- Ctrl + S : Sauvegarder (si supporté)
- Flèches : Navigation
- Shift + Flèches : Sélection

Notes :
- L’application lit et écrit en UTF-8.
- Les caractères invalides apparaissent sous la forme du symbole �.
- La taille de police suit les réglages du système.
- Le défilement vertical peut être contrôlé via le bouton "↓".

Auteur :
Gabriel - Projet minimaliste, optimisé pour la compatibilité et la simplicité.

🌐 English
TABLEAU ASCII
-------------
An application that allows you to create tables like those generated by MySQL, for example.
- Enter your text, separated by semicolons ; in the field at the top.
- Then click "Convert" to generate the table, it will appear in the field at the bottom.
- Click "Copy" to copy the text into your press kit.
- The "Clear" button erases what you typed in the first field, as well as the generated table.
You can change the data separator and the maximum width of the generated table. When the table
reaches the maximum width, the text will wrap to the next line within the cells.
The "Default Values" button restores the default separator and width.
You can run it with the quick tile or the home screen.


ÉDITEUR DE TEXTE
----------------
A simple and lightweight text editor designed for older and modern devices.
Built to be fast, minimalistic and reliable, with no heavy dependencies or
unnecessary features.

Main features:
- Multiple tabs
- Open and save through the Android file picker
- Search with highlighting and navigation
- Text replacement
- Duplicate current line
- Delete current line
- Paste at the exact cursor position
- Quick "scroll to bottom" button
- Transparent interface
- Android 4.1+ compatibility

Keyboard shortcuts (physical keyboard or Unexpected Keyboard):
- Ctrl + Z : Undo
- Ctrl + Y : Redo
- Ctrl + A : Select all
- Ctrl + C : Copy
- Ctrl + V : Paste
- Ctrl + X : Cut
- Ctrl + S : Save (if supported)
- Arrow keys : Navigation
- Shift + Arrows : Selection

Notes:
- The app reads and writes files in UTF-8.
- Invalid characters appear as the � replacement symbol.
- Font size follows the system settings.
- Vertical scrolling can be controlled using the "↓" button.

Author:
Gabriel - Minimalistic project focused on compatibility and simplicity.

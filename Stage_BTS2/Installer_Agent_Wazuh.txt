LINUX - INSTALLATION AGENT (DEBIAN / UBUNTU / ROCKY / ALMA)
# 1) Télécharger l'agent
curl -s https://packages.wazuh.com/key/GPG-KEY-WAZUH \
| sudo gpg --dearmor -o /usr/share/keyrings/wazuh.gpg

echo "deb [signed-by=/usr/share/keyrings/wazuh.gpg] \
https://packages.wazuh.com/4.x/apt/ stable main" \
| sudo tee /etc/apt/sources.list.d/wazuh.list

# 2) Installer l'agent
sudo apt update
sudo apt install wazuh-agent -y

# 3) Configurer le Manager
sudo nano /var/ossec/etc/ossec.conf

<server>
  <address>IPduManager</address>   # IP du Manager
  <port>1514</port>
  <protocol>tcp</protocol>
</server>

# 4) Activer et démarrer
sudo systemctl enable wazuh-agent
sudo systemctl start wazuh-agent

# 5) Vérifier
sudo systemctl status wazuh-agent

---

WINDOWS - INSTALLATION AGENT (MSI + AUTO-CONFIG)
# 1) Télécharger l'agent Windows
https://packages.wazuh.com/4.x/windows/wazuh-agent-4.x.msi

# 2) Installer (double‑clic ou PowerShell)
msiexec.exe /i wazuh-agent-4.x.msi /qn

# 3) Configurer le Manager
Éditer le fichier :
C:\Program Files (x86)\ossec-agent\ossec.conf

Ajouter / modifier :

<server>
  <address>IPduManager</address>   # IP du Manager
  <port>1514</port>
  <protocol>tcp</protocol>
</server>

# 4) Démarrer le service
sc start wazuh-agent

# 5) Vérifier
sc query wazuh-agent

DÉSINSTALLATION AGENT (OPTIONNEL)
Linux :
sudo systemctl stop wazuh-agent
sudo apt remove --purge wazuh-agent -y
sudo rm -rf /var/ossec

Windows :
msiexec.exe /x wazuh-agent-4.x.msi /qn

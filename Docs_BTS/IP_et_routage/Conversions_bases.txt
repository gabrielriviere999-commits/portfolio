CONVERSIONS ENTRE BASE 2, 10 ET 16
===================================

1) DECIMAL (BASE 10) → BINAIRE (BASE 2)
---------------------------------------

Partie entière :
- Divisions successives par 2.
- On note le reste (0 ou 1).
- Lecture de bas en haut.

Exemple :
13 / 2 = 6 r1
6 / 2 = 3 r0
3 / 2 = 1 r1
1 / 2 = 0 r1
=> 13 = 1101

Partie décimale :
- Multiplications successives par 2.
- On note la partie entière obtenue.
- Lecture de haut en bas.

Exemple :
0.375 * 2 = 0.75 → 0
0.75 * 2 = 1.5 → 1
0.5 * 2 = 1 → 1
=> 0.375 = 0.011

Exemple complet :
13.375 = 1101.011


2) BINAIRE (BASE 2) → DECIMAL (BASE 10)
----------------------------------------

Partie entière :
Chaque bit vaut 2^n.

Exemple :
1101 = 1*2^3 + 1*2^2 + 0*2^1 + 1*2^0 = 13

Partie décimale :
Chaque bit vaut 2^-n.

Exemple :
0.011 = 0*2^-1 + 1*2^-2 + 1*2^-3 = 0.375

Exemple complet :
1101.011 = 13.375


3) HEXADECIMAL (BASE 16) → BINAIRE (BASE 2)
-------------------------------------------

Correspondances hex → binaire (4 bits) :
0=0000  1=0001  2=0010  3=0011
4=0100  5=0101  6=0110  7=0111
8=1000  9=1001  A=1010  B=1011
C=1100  D=1101  E=1110  F=1111

Exemple :
3C.1A =
3 → 0011
C → 1100
1 → 0001
A → 1010
=> 0011 1100.0001 1010


4) BINAIRE (BASE 2) → HEXADECIMAL (BASE 16)
-------------------------------------------

Méthode :
- Regrouper les bits par 4.
- Compléter avec des zéros si nécessaire.
- Convertir chaque groupe.

Exemple :
1011.011 =
1011 → B
011 → 0110 → 6
=> B6


5) HEXADECIMAL (BASE 16) → DECIMAL (BASE 10)
--------------------------------------------

Chaque chiffre vaut : chiffre * 16^n

Exemple partie entière :
3C = 3*16^1 + 12*16^0 = 48 + 12 = 60

Exemple partie décimale :
1A = 1*16^-1 + 10*16^-2
= 0.0625 + 0.0390625
= 0.1015625

Exemple complet :
3C.1A = 60.1015625


6) DECIMAL (BASE 10) → HEXADECIMAL (BASE 16)
--------------------------------------------

Partie entière :
Divisions successives par 16.

Exemple :
60 / 16 = 3 r12 → C
=> 60 = 3C

Partie décimale :
Multiplications successives par 16.

Exemple :
0.1015625 * 16 = 1.625 → 1
0.625 * 16 = 10 → A
=> 0.1015625 = 0.A

Exemple complet :
60.1015625 = 3C.1A


7) SYNTHESE RAPIDE
------------------

Base 10 → Base 2 : diviser/multiplier par 2
Base 2 → Base 10 : puissances de 2
Base 16 → Base 2 : 1 hex = 4 bits
Base 2 → Base 16 : groupes de 4 bits
Base 16 → Base 10 : puissances de 16
Base 10 → Base 16 : diviser/multiplier par 16

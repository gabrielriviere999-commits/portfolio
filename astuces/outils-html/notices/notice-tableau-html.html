Code du tableau

  • Pour afficher le code du tableau, cliquer sur Générer le code.
  • Pour copier le code du tableau, cliquer sur Copier le code.
  • Pour éviter les conflits de styles globaux lors de l'utilisation de plusieurs tableaux dans une même page HTML, il faut définir un ID pour chaque tableau.
  • Pour afficher le tableau à partir du code, cliquer sur Mettre à jour le tableau.
  • Pour nettoyer un tableau HTML exporté par LibreOffice Calc, cliquer sur Importer HTML ou faire glisser le fichier dans la zone du code, puis cocher Nettoyer LibreOffice, puis Mettre à jour le tableau et Générer le code.

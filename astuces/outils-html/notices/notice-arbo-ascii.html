Arborescence

Cliquer sur un dossier/ pour y aller.

Boutons

  • [C] : Ajouter un commentaire sur le dossier/ ou fichier, laisser vide pour n'en mettre aucun.
  • [R] : Renommer le dossier/ ou fichier.
  • [X] : Effacer le dossier/ ou fichier.

Champ

  • Cliquer sur Copier texte pour copier le texte brut sans couleurs de l'arborescence.
  • Cliquer sur Copier HTML couleur pour copier le code HTML avec couleurs de l'arborescence.
  • Cliquer sur Mettre à jour à partir du texte pour afficher l'arborescence à partir du texte obtenu avec cet outil, le script Python make-arbo.py ou l'application Android Arbo.
  • Cliquer sur Importer (commande tree) pour afficher l'arborescence à partir du texte obtenu avec la commande tree.
Note : En important l'arborescence de tree, les fichiers sans extensions (sans . à la fin) sont reconnus comme des dossiers.

Notice - Arborescence ASCII & HTML

Arborescence

  • Renommer racine : Changer le nom du dossier qui est tout en haut.
  • + Dossier : Ajouter un dossier.
  • + Fichier : Ajouter un fichier.
  • ← Remonter : Se déplacer en arrière dans l'arborescence.
  • Dossier courant : Affiche le chemin courant.
Cliquer sur un dossier/ pour y aller.
  • [C] : Ajouter un commentaire à droite du dossier/ ou fichier, laisser vide pour n'en mettre aucun.
  • [R] : Renommer le dossier/ ou fichier.
  • [X] : Effacer le dossier/ ou fichier.
  • Copier texte : Copier le texte brut sans couleurs de l'arborescence dans le presse-papiers.
  • Copier HTML couleur : Copier le code HTML avec couleurs de l'arborescence dans le presse-papiers.
  • Afficher texte : Afficher le texte brut sans couleurs de l'arborescence en dessous du bouton.
  • Afficher HTML couleur : Afficher le code HTML avec couleurs de l'arborescence en dessous du bouton.

Champ

  • Mettre à jour à partir du texte : Afficher l'arborescence à partir du texte obtenu avec cet outil, le script Python make-arbo.py ou l'application Android Arbo.
  • Importer (commande tree) : Afficher l'arborescence à partir du texte obtenu avec la commande tree.
  • Importer fichier... : Choisir un fichier depuis l'appareil à mettre dans le champ de texte.
Note : En important l'arborescence de tree, les fichiers sans extensions (sans . à la fin) sont reconnus comme des dossiers.
